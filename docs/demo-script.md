# Demo Script

1. Start PostgreSQL/pgvector with Docker Compose.
2. Start the FastAPI backend.
3. Seed demo patient data.
4. Start Angular.
5. Open the workbench.
6. Select Emily Carter.
7. Create a new case.
8. Upload any dental X-ray image.
9. Run analysis.
10. Show the overlay findings and confidence filter.
11. Run the LangGraph RAG Agent.
12. Show clinical draft, evidence, and tool trace.

## Interview Talking Point

The important part is not the mock model accuracy. The important part is the full AI workflow: image-to-structured-finding, patient-scoped custom retrieval, LangGraph tool orchestration, LangChain structured generation, and UI review.
